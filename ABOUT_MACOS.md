## Longer description

Com-Press is a desktop utility created and published by **Benedict S. Leoveras**.
Its radial action wheel puts compression and conversion tools beside the file
you are working with. Select a Finder or Desktop item, press and hold the left
mouse button or trackpad click, then choose a category and an action.

The app combines archive tools, PDF and DOCX operations, picture conversion,
and audio and video conversion. Tasks run locally, and the dashboard shows
progress. The menu bar keeps Com-Press available after the dashboard is closed.

Version **1.4.6** has a macOS universal2 installer containing Intel and Apple
silicon code with a macOS 11 Big Sur deployment target. Runtime checks have
passed on an Intel Big Sur Mac. Apple silicon and newer macOS execution tests
remain pending. The Finder wheel requires user-approved Accessibility and
Finder Automation permissions.

The current edition is for the publisher's own private evaluation, with a
license agreement and no activation key. Third-party licensing restrictions
must be resolved before sharing the current installer with other recipients.
