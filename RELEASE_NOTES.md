# Com-Press 1.4.6

Com-Press is a Windows desktop utility for local file compression and conversion, organized through a category-based radial wheel.

## In this release

- PDF merge previews the actual pages, supports adding more PDF files, and merges pages in the order shown in the preview.
- Each PDF source is identified with a numbered, color-matched label.
- Improved app launch and window activation when an older release is still running in the system tray.
- Includes a portable application bundle with its runtime, conversion libraries, FFmpeg, and UI assets.

## Downloads

- `Com-Press-Setup-1.4.6.exe` installs Com-Press.
- `Com-Press-1.4.6-Portable.zip` is the complete portable Windows build. Extract the archive and keep the `Com-Press` folder together.

SHA-256 values for the installer and portable bundle are in `SHA256SUMS.txt`.
